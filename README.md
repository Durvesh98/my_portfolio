# Durvesh Patil — Personal Portfolio

A responsive, dark-themed portfolio built with plain HTML, CSS, and JavaScript. No build tools or frameworks required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. For best results, use a local server such as VS Code Live Server.

## Personalise before publishing
1. **Photo:** Add your photo at `assets/durvesh-photo.jpg`. Create the `assets` folder if needed. Use a photo you have permission to publish.
2. **Social links:** Edit the `PROFILE` object at the top of `script.js` and replace the LinkedIn and Instagram starter URLs with your actual profile links.
3. **Video portfolio:** In `index.html`, find the `#creative` section and replace the starter Instagram / YouTube URLs with links to your actual videos. The current cards are placeholders, not real video embeds.
4. **WhatsApp:** The current `wa.me` link uses the phone number shown on the resume. Confirm you want that number public before deploying.
5. **Video editing:** Add the editing software you use (e.g. Premiere Pro, DaVinci Resolve, CapCut) and only list tools you genuinely know.
6. **Resume:** If you want a downloadable resume button, add a PDF you want to publish and link to it from the hero section.

## Included
- Single-page responsive layout with a consistent visual theme
- Mobile navigation
- Animated rotating hero role
- Filterable skills
- Experience timeline, projects, education and certifications
- Email and WhatsApp contact links
- Video-editing showcase placeholders
- Reduced-motion accessibility support

## Important
This is a front-end static site. The email link opens the visitor's email application; there is no backend contact-form storage. Do not add passwords, private work documents, or confidential company information to a public portfolio.
